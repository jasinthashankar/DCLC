# Enterprise Zero-Trust Network and Firewall Policy

## 1. Perimeter Defense Architecture
All public incoming ingress traffic must terminate at Cloudflare edge proxies before entering private subnet ranges.
Direct IP access to origin nodes is strictly prohibited and dropped by hardware border routers.
Subnets are isolated into Tier 1 Web, Tier 2 Application Services, and Tier 3 Storage Database segments.
Lateral movement across tiers requires authenticated JWT tokens signed by the central Identity Provider.

## 2. TLS Encryption and Certificate Authority
All intra-cluster service communication must enforce TLS 1.3 with forward secrecy ciphers.
Internal certificates are generated by HashiCorp Vault with an automatic 7-day rotation window.
Weak cipher suites including RC4, 3DES, and CBC-mode AES are permanently disabled in all proxy profiles.
Certificate expiry metrics are scraped continuously into Prometheus with alerts paging on call engineers.

## 3. Whitelisting and IP Restrictions
Storage control planes only accept connections originating from the internal VPN gateway subnet 10.240.0.0/16.
Bastion host SSH access requires FIDO2 hardware security keys and two-person authorization for root shells.
Failed authentication attempts trigger automated IP blocking across distributed firewall tables for 24 hours.
Egress traffic is restricted to pre-approved cloud storage endpoints and monitored via VPC flow logs.
